# PDF export fonts

Noto Sans Regular and Bold are bundled so PDF exports can render accented Latin,
Greek and Cyrillic text without relying on fonts installed on the server.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Downloaded unchanged on 2026-09-04. The upstream SIL Open Font License is included
in `OFL.txt`. Other scripts may require additional fonts.
